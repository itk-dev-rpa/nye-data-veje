# ODE Ingest from KMD Opus Debitor to SQL
This is a repo for mapping data from KMD Opus Debitor through ODE extracted files.

# Usage
The scripts are designed to be run through OpenOrchestrator via `robot_framework/process.py`.

## How it works
The pipeline automatically processes all available files in the data directory:

1. **File Discovery**: Finds all files matching `{TableName}_{Total|Delta}` pattern
2. **Staging**: Loads and filters data according to `table_definitions`, inserts into `{TableName}_{Subset}_Staging`
3. **Transformation**: Executes SQL transformation script that moves data through:
   - `_Staging` → `_Backup` (raw data preservation)
   - `_Staging` → `_Typed` (typed & cleaned data)
   - `_Typed` → Final table (merge/upsert with validation)
4. **Archival**: Moves processed files to archive folder
5. **Logging**: Logs ingest stats and validation results to database and `transform_validation.json`

The pipeline processes both Total and Delta files for all tables defined in `process.py:14-32`.

## SQL Transformations
The transformations are defined in `ode_ingest/sql_transforms/transform_*.sql`. These are generated by running `python robot_framework/ode_ingest/generate_transform_sql.py`. This must be done after any changes to tables defines in `ode_ingest/table_definitions.py`.
